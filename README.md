# Google Translate QA Assessment

## Overview

This repository contains the QA assessment conducted for **Google Translate – Text Translation**.

The assessment focuses on manual testing of text translation functionality, including functional testing, language translation, input validation, UI behavior, error handling, and other relevant test scenarios.

## Testing Documents

Test Plan-Defines the testing scope, objectives, approach, test areas, and test conditions.  
Test Cases-Contains the detailed test cases executed during testing.                          
Bug Report-Contains the defects identified during testing with relevant details and evidence. 
Test Summary Report-Provides the overall testing results, execution summary, defects, and QA sign-off. 

## Evidence

The `Evidence` folder contains screenshots supporting the reported defects.

## Testing Type

* Manual Testing
* Functional Testing
* UI Testing
* Validation Testing
* Negative Testing
* Exploratory Testing
* Translation Quality Testing

**Application:** Google Translate – Text Translation
